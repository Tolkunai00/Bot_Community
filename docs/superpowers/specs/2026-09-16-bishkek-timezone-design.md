# Переход расписания на время Бишкека

## Цель

Перевести расписание Telegram-бота с `Asia/Almaty` на `Asia/Bishkek`, включая уже подключённые группы.

## Изменения

- Установить `Asia/Bishkek` как часовой пояс по умолчанию в конфигурации и примере окружения.
- Обновить часовой пояс обеих существующих подключённых групп в SQLite на `Asia/Bishkek` без изменения остальных данных.
- Сохранить текущее расписание: открытие в 18:00, напоминание в 20:00 и итог в 21:00 по времени Бишкека.
- Обновить README, чтобы документированное время совпадало с фактической конфигурацией.

## Совместимость и обработка ошибок

Имена заданий, тексты сообщений, Telegram-темы, участники и отчёты не меняются. Конфигурация продолжит проверять название часового пояса через `pytz`; неизвестное значение остановит запуск с понятной ошибкой.

## Проверка

- Тест конфигурации подтвердит значение `Asia/Bishkek` по умолчанию.
- Тесты планировщика подтвердят расписание 18:00 / 20:00 / 21:00 в `Asia/Bishkek`.
- Проверка базы подтвердит, что все подключённые группы используют `Asia/Bishkek` и база остаётся целой.
- Полный набор тестов должен завершиться без ошибок.
