# Шуточная строка в напоминании на 20:00

## Цель

Сделать напоминание для участников, которые не отправили отчёт к 20:00, более выразительным и дружелюбным.

## Изменение

- В самое начало напоминания перед закрытием добавить отдельную строку `😂 <b>Ээээ, кетир отчёт!</b>`.
- После неё сохранить существующий заголовок напоминания, упоминания участников, ссылку на бота и инструкцию `/standup`.
- Использовать уже включённый для сообщения HTML-режим, чтобы шуточная строка отображалась жирным шрифтом.

## Границы

- Не менять напоминание об открытии в 18:00.
- Не менять итоговое сообщение и закрытие приёма в 21:00.
- Не менять расписание, выбор участников, ссылки, команды и остальную логику бота.

## Проверка

- Автоматический тест проверяет, что сообщение на 20:00 начинается с `😂 <b>Ээээ, кетир отчёт!</b>`.
- Полный существующий набор тестов должен продолжать проходить.
